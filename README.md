# Unwrapped

**The tools these apps charge $70–135/month for, minus the wrapper.**

## 🔗 [dadude044.github.io/unwrapped](https://dadude044.github.io/unwrapped/)

---

Resume.io, CoverPaste, Coverler, LinkedIn "AI optimizer" tools, and $25–70/mo case-interview coaches are, underneath, a prompt wrapped in a subscription. This is that prompt, free, powered by Google's Gemini API using a key you provide yourself.

## What it does

| # | Tool | What it does |
|---|------|--------------|
| 01 | Resume | Tightens rough bullets into quantified, resume-ready lines |
| 02 | Cover letter | Turns your background + a job description into a specific 3-paragraph letter |
| 03 | LinkedIn | Writes a headline + About section tuned for recruiter search |
| 04 | Case prep | Runs a live, turn-by-turn mock consulting case interview |
| 05 | Price check | Shows what each tool above would cost as a paid subscription |

## How it works

One HTML file, no backend, no database, no server. Your browser talks directly to Google's Gemini API using a free key you get from Google. Nothing you type is ever stored anywhere except your own browser session.

Everything is free. The site walks you through getting your key step by step.

## A note on what this is

This is a personal, open-source developer project — a demonstration of calling Google's Gemini API from a static page with a user-supplied key. Not affiliated with Resume.io, CoverPaste, Coverler, LinkedIn, or any case-prep tool named on the site's Price Check page.
